# Exile Route 1.1.0

Exile Route 1.1.0 turns the active zone into a complete campaign checklist and makes local development builds keep a stable macOS identity.

Highlights:

- every objective for the current zone visit stays visible, including its exit;
- manual Previous and Next navigation now follows individual objectives;
- skipped objectives remain recoverable when OCR confirms the next zone;
- OCR progression is restricted to the expected exit of the active visit;
- compact overlay height adapts to the checklist content;
- the panel opens at the top-right, directly below the configured OCR title region;
- version, build number, and exact Git revision are visible in the menu and About view;
- free certificate-backed local signing avoids repeated Screen Recording permission prompts across development builds.

The application targets Apple Silicon and requires macOS 15 or newer. The public archive is ad hoc signed and is not notarized, so its first launch must be approved with Finder's **Open** command.

The release archive contains no proprietary Path of Exile visual assets. Route content is attributed to HeartofPhos and bundled under its MIT license.
