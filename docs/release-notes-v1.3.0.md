# Exile Route 1.3.0

Exile Route 1.3.0 turns Settings into a reliable, reusable control center and adds direct keyboard-shortcut recording.

Highlights:

- **Settings…** now opens a populated native window every time;
- reopening Settings focuses the same window instead of creating duplicates;
- click any global shortcut and press the replacement combination;
- use letters, numbers, arrows, Space, or F1–F12 with two to four modifiers;
- duplicate combinations are rejected with a visible warning;
- `Escape` cancels recording and **Restore defaults** restores all original controls;
- legacy saved shortcuts remain compatible and invalid duplicates are repaired safely.

The application targets Apple Silicon and requires macOS 15 or newer. The public archive is ad hoc signed and is not notarized, so its first launch must be approved with Finder's **Open** command.

The application includes no proprietary Path of Exile visual assets. Route content is attributed to HeartofPhos and bundled under its MIT license.
