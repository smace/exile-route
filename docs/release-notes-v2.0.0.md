# Exile Route 2.0.0

Exile Route 2.0.0 brings Path of Building directly into the campaign route.

- Import a PoB code, XML or text file, clipboard value, or supported HTTPS share link from **Settings → Build**.
- Read every enabled modern or legacy skill set, normalize Vaal and Awakened variants, and keep unknown gems visible as warnings.
- Add eligible quest rewards and the earliest class-compatible vendor purchases to the existing campaign checklist.
- Show the vendor, currency cost, skill-set context, and an original attribute-colored gem glyph.
- Preserve the current campaign objective and route options when a build is imported, replaced, or removed.
- Keep older state files and route caches compatible while updating routes, quests, characters, and gem catalogs from one upstream commit.

PoB downloads are streamed under strict size limits, XML external entities remain disabled, and the raw PoB code is never persisted. Passive trees, equipment, flasks, and calculation settings are intentionally excluded.

The application targets Apple Silicon and requires macOS 15 or newer. Public archives remain ad hoc signed and are not notarized.
