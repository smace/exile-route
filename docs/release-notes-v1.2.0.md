# Exile Route 1.2.0

Exile Route 1.2.0 makes the overlay freely positionable without weakening its normal click-through behavior.

Highlights:

- enable interaction mode with `Control-Option-I`, then drag the panel from any point;
- drag the overlay freely across displays;
- automatically save its final position and last display;
- press `Control-Option-I` again to lock the panel and restore click-through;
- find the same action in the menu bar as **Move overlay** / **Lock overlay position**;
- keep the movement gesture visible in the interaction footer and Settings;
- package the exact application produced by the Release build.

The application targets Apple Silicon and requires macOS 15 or newer. The public archive is ad hoc signed and is not notarized, so its first launch must be approved with Finder's **Open** command.

The application includes no proprietary Path of Exile visual assets. Route content is attributed to HeartofPhos and bundled under its MIT license.
