# Exile Route 1.0.0

The first stable release of Exile Route brings the complete Path of Exile campaign route to a quiet native macOS overlay designed for GeForce NOW.

Highlights:

- complete ten-act offline route based on a pinned HeartofPhos snapshot;
- original compact and expanded dark occult interface;
- local-only area recognition with ScreenCaptureKit and Vision;
- conservative automatic progression with two-detection confirmation and no regression;
- configurable global shortcuts and menu-bar controls;
- custom route import/export and validated atomic upstream updates;
- persistent progress and per-display overlay placement;
- unit, rollback, OCR fixture, persistence, and visual snapshot tests.

The application is ad hoc signed for Apple Silicon and requires macOS 15 or newer. It is not notarized, so the first launch must be approved with Finder's **Open** command.

The release archive includes no proprietary Path of Exile visual assets. Route content is attributed to HeartofPhos and bundled under its MIT license.
